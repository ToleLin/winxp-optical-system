XP 光學系統 使用說明
====================

在 Windows 10 / 11 上執行只能在 Windows XP 運作的光學軟體，並把 HORIBA iHR320 分光儀（USB）接進去。

【極簡流程】（安裝檔下載：https://github.com/ToleLin/winxp-optical-system/releases/latest）
1. 把自己的 XP 安裝光碟 ISO 檔改名為 xp.iso，和 XPOptical-Setup 安裝檔放在同一個資料夾。
2. 執行安裝檔，一路按「下一步」。
3. 程式自動開啟後輸入 XP 產品序號，按「開始自動安裝」，約 30–90 分鐘後自動進入 XP 桌面。
4. 把光學軟體的安裝檔資料夾拖進視窗，在 XP 裡安裝；按「設定」選擇 iHR320。
   之後關閉直接按 ✕，下次開啟回到原本的畫面。
以下是各步驟的詳細說明。


一、安裝
--------
1. （建議）把自己的 Windows XP 安裝光碟 ISO 檔改名為 xp.iso，
   放在 XPOptical-Setup 安裝檔的同一個資料夾。沒有也可以，之後再選擇。
2. 執行 XPOptical-Setup 安裝檔。
   若 Windows 顯示「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。
   若顯示「應用程式控制原則已封鎖此檔案」且沒有「仍要執行」可按，見「六、常見問題」。
3. 依畫面按「下一步」→「安裝」。會一併：
   - 安裝 iHR320 連到 XP 所需的 USB 驅動（UsbDk）
   - 在桌面建立「XP 光學系統」捷徑
   - 若旁邊有 xp.iso，一起複製進去
   程式預設安裝在 C:\XPOptical（路徑只含英文與數字最保險）。

（免安裝版：把整個 XPOptical 資料夾解壓縮到 C:\XPOptical，雙擊 XPOptical.exe；
  第一次開啟時按右下角「安裝 USB 驅動」。）


二、第一次使用（只需要做一次）
------------------------------
1. 自動安裝 XP
   開啟程式後會出現「自動安裝 XP」（或按「自動安裝 XP（建議）…」）：
   確認 XP 安裝光碟（ISO）→ 輸入產品序號（25 碼）→「開始自動安裝」。
   - 全程自動：分割磁碟、安裝、重新開機數次，約 30–90 分鐘，完成後直接進入 XP 桌面。
   - 出現「Press any key to boot from CD」時不要按任何鍵。
   - 可以最小化視窗，但請不要關閉程式。
   - 完成後，程式資料夾（C:\XPOptical）裡的 xp.iso 只有重新安裝 XP 時才會用到，
     要節省空間（約 600 MB）可以刪除。
   （進階：也可以選「手動安裝 XP…」照 XP 原本的安裝畫面自己操作，完成後按「✔ XP 安裝完成」。）

2. 安裝光學軟體與 iHR320 驅動
   把光學軟體與驅動的安裝檔資料夾直接拖進視窗
  （或用工具列「放入檔案 ▼」→「匯入資料夾」），程式會把它做成光碟放進 XP。
   在 XP 的「我的電腦」開啟光碟機，照原本的方式安裝。

3. 設定 iHR320
   按「設定」，在「iHR320 是哪一個 USB 裝置？」選擇 iHR320。
   不確定是哪一個：先拔掉 iHR320 的 USB 線按「重新整理」，再插上按一次，新出現的就是 iHR320。
   之後只要插上 USB 線並開啟儀器電源，狀態列就會顯示「iHR320：已連線」。


三、日常使用
------------
- 開啟：雙擊 XPOptical.exe，數秒內回到上次關閉時的畫面（光學軟體仍開著）。
- 關閉：直接按視窗右上角的 ✕，程式會自動保存 XP 的狀態。
  （在「設定」可改成每次關閉時讓 XP 正常關機。）
- Ctrl+Alt+Del：Windows 會攔截這組按鍵，請用工具列的「Ctrl+Alt+Del」按鈕。


四、把量測資料拿出來
--------------------
XP 預設不連網（安全考量）。目前版本請用 USB 隨身碟：
1. 把隨身碟插到電腦上。
2. 「設定」→「其他要連到 XP 的 USB 裝置」勾選該隨身碟 → 確定。隨身碟會出現在 XP 裡。
3. 在 XP 裡把資料複製到隨身碟，然後「安全地移除硬體」。
4. 回到「設定」取消勾選，隨身碟就會回到 Windows。
（之後的版本會自動把 XP 裡的量測資料同步到 Windows。）


五、狀態列說明
--------------
- XP：執行中 / 已關機 / 安裝中
- iHR320：已連線（綠）、連線中（黃）、未偵測到（灰，請確認 USB 線與電源）、連線失敗（紅，滑鼠移上去看原因）
- 軟體模擬：XP 以軟體模擬執行，不需要開啟 Hyper-V 或任何 Windows 功能。


六、常見問題
------------
Q：安裝檔或程式被擋下：「應用程式控制原則已封鎖此檔案」
  （An Application Control policy has blocked this file），沒有「仍要執行」可按？
A：這是 Windows 11 的「智慧型應用程式控制」，會擋下沒有數位簽章的程式（本程式目前沒有簽章）。
   到「Windows 安全性」→「應用程式與瀏覽器控制」→「智慧型應用程式控制設定」選「關閉」，再重新執行。
   注意：部分 Windows 版本關閉後，要重設 Windows 才能再開啟。公司或學校管理的電腦請先詢問 IT 人員。

Q：出現「這個路徑含有中文或特殊字元」？
A：請把 XPOptical 資料夾移到只含英文與數字的位置，例如 C:\XPOptical。

Q：iHR320 顯示「連線失敗：無法開啟裝置」？
A：請關閉 Windows 上正在使用 iHR320 的其他程式，並確認已安裝 USB 驅動。

Q：關閉時出現「XP 沒有回應關機要求」？
A：通常是 XP 裡有程式在等待儲存。選「否」回到 XP 處理後再關閉；選「是」會強制關閉（未儲存的資料會遺失）。

Q：要更新到新版？
A：先在程式中按工具列的「■ 關機」讓 XP 正常關機，再關閉程式（新版的執行引擎可能無法恢復舊版的休眠狀態），
   再到 https://github.com/ToleLin/winxp-optical-system/releases/latest 下載新的安裝檔直接執行。
   XP 環境、光學軟體與設定都會保留。

Q：要解除安裝？
A：「設定 → 應用程式」或開始功能表的「XP 光學系統 → 解除安裝」。
   會詢問是否一併刪除 XP 環境；選「否」會保留，重新安裝後可以直接繼續使用。

Q：要回報問題？
A：按「設定」→ 左下角「產生問題回報…」，桌面會出現一個 XPOptical-report-日期.zip，
   把這個檔案（與問題截圖）傳給開發者即可。檔案內含紀錄檔、設定與電腦環境資訊，
   不含 XP 磁碟與量測資料。
